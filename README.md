# USTP Student GWA Calculator

**Name:** Jastin Alberca 
**Section:** IT3R4 

## Description
A command-line Python application designed to compute a student's General Weighted Average (GWA) based on the official USTP grading system (1.00 to 5.00 numerical scale).

## How to Run
Ensure Python 3 is installed, then execute:
```bash
python ustp_calculator.py
